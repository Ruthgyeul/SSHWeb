# docs/

AI and contributor guidance for **TerminalWebTemplate**. **Every AI agent and
contributor must read these in full before starting any work** — they are the
source of truth for the project's architecture and conventions. The root
[`CLAUDE.md`](../CLAUDE.md) imports them so Claude Code loads them automatically;
other tools are pointed here by [`AGENTS.md`](../AGENTS.md).

| Guide | Scope |
| ----- | ----- |
| [`claude-project.md`](claude-project.md) | Project-wide picture — stack, commands, architecture & conventions |
| [`claude-src.md`](claude-src.md) | `src/` source layout and rules of thumb |
| [`claude-components.md`](claude-components.md) | `src/components/` UI conventions |
| [`git-workflow.md`](git-workflow.md) | Branching strategy (GitHub Flow) — visualized, with the change lifecycle |

> Keep the placeholder discipline described in
> [`CONTRIBUTING.md`](../CONTRIBUTING.md): no real domains, names, emails, or
> secrets in committed files.
